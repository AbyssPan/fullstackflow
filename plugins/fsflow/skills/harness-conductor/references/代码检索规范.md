# 代码检索规范（查找代码时按需读取）

本文件供编排过程中定位代码时按需读取。

1. 给出文件路径、组件或类名时，使用 `kb-query.cjs` 精确定位；业务概念先检索知识库总览。
2. 读取命中源码和相关文档章节。同一源码版本已有的定位与影响面证据直接复用。
3. 共享组件、Store、公共服务/接口、公共工具变更，以及涉及上游入口的 Bug，必须用源码搜索和按需 LSP 查引用确认调用方、间接入口与回归项；局部改动按实际范围查证。
4. 证据记录仓库/文件/符号、提交号及相关工作区 diff 或文件摘要、查证位置、调用方、回归项和未确认范围，写进已有任务描述/交付说明。复用前确认相关源码未变，不能只比较 HEAD。
5. graphify 是可选增强。已建图谱按需查询，引用关系前核实源码和图谱新鲜度；存在不代表最新，查询未命中不代表无依赖。缺失或失败时记录原因并用 `search_content` / `search_file` / Grep 和按需 LSP 继续查证，不反复探测、不自动建图。
6. 审查检查调用方证据及其回归覆盖，不以工具名称或调用次数记 debt。动态注册、别名、路由等未确认的依赖如实交接，不猜测。

不得猜测文件路径和调用关系。当前实现事实冲突以源码为准；编码规范以知识库为准，疑似过期内容记录证据交 Phase 6 确认是否更新。
