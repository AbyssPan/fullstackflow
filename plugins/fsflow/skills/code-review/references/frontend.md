# 前端复核与误报边界

- **功能**：AC 所需入口、渲染、交互、持久化与错误反馈是否真实连接；检查缺省值与空值、请求参数、迟到响应、账号切换和生命周期清理。
- **组件集成**：查路由、父组件、注册表、自动导入配置、动态 import 和模板。只有证实需求要求的入口不可达时才报告；组件库导出、自动注册或间接引用不能因没有页面直接 import 而报错。
- **契约**：核对路径、方法、字段映射、序列化、分页与错误语义。额外响应字段未被消费本身不是问题；需求必须展示/处理的数据缺失，或前端读取不存在的字段才需查证影响并定级。
- **安全**：验证不可信内容进入 HTML/URL 的路径、已有净化防护与服务端授权边界；不能把纯文本插值误判成注入，也不能认为隐藏按钮等于鉴权。
- **交互与可访问性**：检查键盘、可访问名称、焦点、加载/失败/空态、目标视口；设计未画状态时仍检查项目既有交互规范。
- **性能**：结合数据规模、触发频率和测量判断重渲染、长列表、资源与监听开销。不因没有 memo/虚拟列表自动报告。
- **规范**：用实际框架/编译器/lint 配置判断写法；必要的类型边界、动态样式和合法注册机制不能被模板禁令误报。

每个问题应说明具体触发、证据位置、受影响 AC/入口和修复方向；能通过上下文排除的候选问题不进入问题清单。
