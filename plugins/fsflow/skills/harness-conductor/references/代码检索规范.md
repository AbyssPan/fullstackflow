# 代码检索规范（查找代码时按需读取）

本文件供编排过程中定位代码时按需读取。

1. 给出文件路径、组件或类名时，使用 `kb-query.cjs` 精确定位；业务概念先检索知识库总览。
2. 读取命中源码和相关文档章节。同一源码版本已有的定位与影响面证据直接复用。
3. 跨域影响、调用关系不明、修复根因或证据冲突时，补充 `graphify query/explain/path`。已有图谱只查询，不为普通定位重建。
4. 索引未覆盖或 graphify 不可用时，用 `search_content` / `search_file` 搜索实际源码，不重复尝试不可用工具。

不得猜测文件路径和调用关系。当前实现事实冲突以源码为准；编码规范以知识库为准，疑似过期内容记录证据交 Phase 6 确认是否更新。
